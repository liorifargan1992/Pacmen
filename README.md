# פקמן — משחק לימודי 🟡👻

משחק פקמן שלם בקובץ אחד, שנבנה כדי ללמד **איך תוכנה עובדת** — למי שאין רקע בתכנות אבל יש דמיון טכני.

## איך משחקים

פשוט פותחים את הקובץ `index.html` בדפדפן (לחיצה כפולה עליו). זהו. אין התקנה, אין שרת, אין כלום.

- **חצים / WASD** — תזוזה
- אכלו את כל הנקודות כדי לנצח
- הנקודות הגדולות המהבהבות הופכות את הרוחות למפוחדות (כחולות) — ואז אפשר לאכול *אותן*

## איך המשחק בנוי? המדריך למי שלא מתכנת

### שלושה חומרי בנייה

כל אתר או משחק בדפדפן בנוי משלוש "שפות", וכל אחת עושה עבודה אחרת. תחשבו על בניית בית:

| שפה | תפקיד | האנלוגיה |
|------|--------|-----------|
| **HTML** | מה קיים בדף | השלד והקירות של הבית |
| **CSS** | איך זה נראה | הצבע, הריהוט, העיצוב |
| **JavaScript** | מה קורה ומגיב | החשמל, האינסטלציה, הבית החכם |

בקובץ שלנו שלושתן יושבות יחד: ה-HTML הוא כמה שורות בלבד, ה-CSS קצת יותר, וכמעט הכל זה JavaScript — כי במשחק, רוב העבודה היא "התנהגות".

### הרעיון המרכזי: לולאת המשחק

זה הסוד של **כל** משחק מחשב שנוצר אי פעם, מפונג ועד פורטנייט:

> משחק הוא בעצם סרט הנפשה שמצויר מחדש ~60 פעם בשנייה, וכל "פריים" מחושב לפי חוקים.

בכל שישים-ית שנייה קורים שלושה דברים, בסדר הזה:

1. **קלט** — מה השחקן לחץ?
2. **עדכון** — מפעילים את חוקי המשחק: פקמן זז, הרוחות מחליטות, בודקים התנגשויות
3. **ציור** — מוחקים את המסך ומציירים הכל מחדש לפי המצב החדש

וחוזר חלילה. שום דבר לא "זז" באמת — כמו בקולנוע, זו אשליה של תמונות סטילס מהירות.

### המפה היא סתם טקסט

פתחו את `index.html` וחפשו את `MAZE_TEXT`. תראו את זה:

```
###################
#o.......#.......o#
#.##.###.#.###.##.#
```

זה כל המבוך! `#` = קיר, `.` = נקודה, `o` = נקודת-על, `P` = פקמן, `G` = רוח.

זה מדגים עיקרון עמוק בתכנות: **הפרדה בין נתונים ללוגיקה**. הקוד לא יודע כלום על הצורה של המבוך — הוא רק יודע לקרוא את הטבלה. רוצים מבוך משלכם? תערכו את הטקסט (רק שמרו על 19 תווים בשורה) ותרעננו את הדפדפן. שום שורת קוד אחרת לא צריכה להשתנות.

### איך "יודעים" שפקמן נתקל ברוח?

אין פה קסם — רק מתמטיקה מכיתה ט'. לכל דמות יש נקודת מרכז (x, y). המרחק בין שני מרכזים מחושב עם **משפט פיתגורס**, ואם המרחק קטן מסף מסוים — זו התנגשות. זהו. כל מנועי המשחק הגדולים עושים גרסאות משוכללות של אותו רעיון.

### ה"בינה" של הרוחות — פחות חכמה ממה שנדמה

כל רוח, בכל צומת, עושה דבר פשוט:

- ברוב הפעמים: בוחרת את הכיוון שהכי מקרב אותה לפקמן (או מרחיק, כשהיא מפוחדת)
- לפעמים: בוחרת כיוון אקראי
- ואף פעם לא מסתובבת 180° (חוק מהמשחק המקורי)

לכל רוח יש "מקדם רדיפה" שונה במקצת — ולכן הן מרגישות כמו אישיויות שונות. זה שיעור חשוב על בינה מלאכותית במשחקים: **התנהגות שמרגישה חכמה נוצרת מחוקים טיפשיים + קצת אקראיות.**

### מילון מונחים קטן

- **משתנה (Variable)** — קופסה עם שם שמחזיקה ערך. `score` מחזיק את הניקוד, וכשאוכלים נקודה מחליפים את הערך שבפנים.
- **פונקציה (Function)** — מתכון עם שם. כותבים פעם אחת "איך מציירים רוח" וקוראים לזה שלוש פעמים, פעם לכל רוח.
- **אובייקט (Object)** — קופסה שמאגדת כמה תכונות שקשורות זו לזו. `pacman` מחזיק ביחד את המיקום, הכיוון והמהירות שלו.
- **מערך (Array)** — רשימה. `ghosts` היא רשימה של שלושה אובייקטי-רוח, והקוד עובר עליה "לכל רוח ברשימה — תזיזי את עצמך".
- **אירוע (Event)** — הודעה מהדפדפן: "המשתמש לחץ על מקש!". אנחנו נרשמים מראש להודעות האלה ומגיבים.
- **Canvas** — אלמנט HTML שהוא דף ציור ריק. נותנים לו פקודות כמו "צייר עיגול צהוב כאן" והוא מצייר פיקסלים.

### רעיונות לניסויים (הדרך הכי טובה ללמוד!)

פתחו את `index.html` בעורך טקסט, שנו, שמרו, ורעננו את הדפדפן:

1. **קל:** חפשו `speed: 2.2` — תעשו את פקמן מהיר יותר
2. **קל:** חפשו `lives = 3` — תתחילו עם 9 חיים
3. **בינוני:** חפשו `#ffd700` (הצבע של פקמן) — תחליפו ל-`#00ff00` ותקבלו פקמן ירוק
4. **בינוני:** חפשו `60 * 7` — כמה זמן הרוחות מפוחדות? תשנו את ה-7
5. **מתקדם:** תערכו את `MAZE_TEXT` ותבנו מבוך משלכם
6. **מתקדם:** תוסיפו `G` רביעי למפה — רוח נוספת תופיע מעצמה. למה? כי הקוד קורא את המפה ולא מניח כמה רוחות יש

```

├── index.html   ← כל המשחק: שלד (HTML) + עיצוב (CSS) + מוח (JavaScript)
```
